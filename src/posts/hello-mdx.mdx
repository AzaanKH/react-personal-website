## Markdown works as usual

Paragraphs, *emphasis*, [links](https://mdxjs.com/docs/what-is-mdx/), `inline code`, lists,
and quotes:

- The file name is the URL: `src/posts/hello-mdx.mdx` → `/blog/hello-mdx`
- Frontmatter needs `title`, `description`, and `date`; `draft` is optional
- A single `#` heading renders as a section heading, since the title is the page's `h1`

> GitHub-flavored extras (tables, ~~strikethrough~~, task lists, autolinks) are on too.

| Feature | Syntax |
| --- | --- |
| Component | `<SpringPlayground />` |
| Expression | `{springs.length}` |
| Callout | `<Callout title="…">` |

## JavaScript expressions

Values exported from the post can be used inline. There are {springs.length} presets here:

<ul>
  {springs.map((s) => (
    <li key={s.name}>{s.name}: stiffness {s.stiffness}, damping {s.damping}</li>
  ))}
</ul>
